Glossary
========

.. glossary::

   AEMS
      FDA's Adverse Event Monitoring System, launched in March 2026, which brings adverse event reporting onto one platform.

   Concomitant drug
      A drug the patient was taking alongside the suspect drug.

   FAERS
      FDA Adverse Event Reporting System, the source of openFDA's drug adverse event data.

   MedDRA
      The Medical Dictionary for Regulatory Activities, the standard vocabulary used to code reactions.

   Serious adverse event
      An event that results in death, a life-threatening condition, hospitalisation, disability, a congenital anomaly or another serious outcome.

   Suspect drug
      The drug the reporter believed caused the reaction. FDA doesn't validate this.
